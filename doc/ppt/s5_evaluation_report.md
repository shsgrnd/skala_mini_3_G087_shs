# S5 평가 결과 — 근거 검사와 Judge의 한계

2026-10-21. 운영 요청과 분리한 오프라인 평가다. 수치·단위·시스템·시각·출처는 코드로 검사하고, 해석이 필요한 근거 충실성은 로컬 qwen3:8b Judge로 보조 평가했다. temperature=0, think=false, rubric s5-v1, 코드 검사 s5-code-v3.

운영 서비스 코드는 변경하지 않았다. 평가 도구·데이터·raw는 로컬에 보관하며 최종 보고서만 공개한다.

## 검증과 실험 조건

- 전체 테스트 198 PASS / 기존 13 XFAIL. 평가 전용 41 PASS, 공개 서비스 단위 101 PASS / 5 XFAIL.
- 소스 버전별 동일 합성 사례 3개 × 6단계 = 18행. 같은 fake 서비스 모델과 고정 stdio MCP로 재생했고 현재 설치 의존성을 공통 사용했다.
- 사용자 검토 dev 4개 × 독립 새 호출 3회, 별도 agent 작성 test 4개, 과거 원본 감사 5행.
- dev/test·사례·모델·평가기 버전을 나눠 집계했다. 실패·데이터 충돌은 unscored이며 0점이 아니다.

허용 외 조회 판정은 현재의 명시 대상 정책을 기준으로 한다. 원본의 기대 동작을 사후에 바꿔서 원래 테스트가 실패했다고 표현하지 않는다. 동일 운영 2사례의 정책 위반은 S0 2건에서 strict 적용 후 0건이었다.

Judge 점수는 이 차이를 구분하지 못하고 CPU 응답에 모두 4점을 줬다. 근거를 인용한 답변이라도 요청하지 않은 시스템을 조회했을 수 있으므로 코드 정책 검사를 우선한다. 이 점수로 품질 개선율을 주장하지 않는다.

S4와 integrated는 같은 서비스 커밋이며 S5 평가를 새로운 서비스 품질 개선으로 계산하지 않았다. fake 이름 회상은 모든 버전이 통과했으므로 S4 실모델 개선의 증거로 쓰지 않는다.

## 사람이 확인한 사례와 Judge 변동

| 사례 | 사람 범주 | 대표 차원 점수 3회 | 표준편차 | 지원/미지원 방향 일치 |
|---|---|---|---|---|
| gold-correct | acceptable | [4, 4, 4] | 0.0 | 3/3 |
| gold-wrong-number | numeric_error | [2, 2, 2] | 0.0 | 3/3 |
| gold-invented-log | unsupported_source | [2, 2, 2] | 0.0 | 3/3 |
| gold-uncertain | appropriate_uncertainty | [4, 4, 4] | 0.0 | 3/3 |

사용자는 네 범주 판정을 확인했으며 세부 0~4 점수를 직접 매긴 것은 아니다. gold·정답·버전명은 Judge에서 숨겼다. 지원/미지원의 방향은 12회 모두 일치했지만 독립 사례는 4개뿐이다. 오류 사례에도 중간 점수를 주고 정답 해설을 과장한 사례가 있어 단독 합격 기준으로 사용하기 어렵다. 3회 표준편차 0은 일반 정확도나 결정론의 증명이 아니다.

수치를 인용하지 않은 답변의 numeric 점수는 평균에서 제외했다. 조건부 런북 임계값과 현재 관측값, 권고와 실행, 합성과 실제 운영 사실을 구분했다.

## 한계와 비용

최종 39행 중 38행 채점, 1행은 과거 계측 불일치로 제외했다. 캐시 15행, 신규 로컬 Judge 23회·29297토큰, 로컬 API 청구액 $0. 연산·전력·시간 비용이 없는 것은 아니며 탐색 실행은 이 최종 사용량과 별도다.

제외된 1행은 S2 과거 기록이다. 측정 코드가 원본 MCP 응답(CPU 91%)을 먼저 기록한 뒤, 바깥 합성 데이터 래퍼가 복사본을 CPU 10%로 바꿔 서비스에 전달했다. 답변은 10%를 사용했지만 저장된 근거는 변경 전 91%여서, 저장된 근거를 그대로 정답으로 삼으면 정상 응답을 수치 오류로 오판한다. 요청 시점의 전체 근거를 신뢰성 있게 복원할 수 없어 임의 보정하지 않고 unscored로 보존했으며 Judge도 호출하지 않았다. 별도 동일 조건 재생의 S2 사례는 정상 평가했다.

과거 raw는 당시 모델·질문·fixture 조건이 다르므로 직접 순위를 매기지 않았다. 일부 S2 근거와 답변의 계측 불일치를 발견해 임의 보정하지 않고 평가 불가로 남겼다. 작은 합성 사례, 같은 모델 계열의 자기 선호, 제한된 문법 검사, 의미적으로 틀릴 수 있는 Judge 해설이 남은 한계다. 더 큰 사람 검토 세트와 다른 Judge 모델을 통한 검증이 필요하다.
